# 角色强调色设计

## 目标

选择角色时，将该角色的默认文字颜色同时应用到操作界面的强调色。手动修改文字颜色不会改变界面主题。

## 方案

应用根据角色默认颜色的色相与明暗程度，在 Radix Themes 支持的颜色中选择最接近的一组。Radix 的按钮、开关、滑杆、输入焦点和弹出内容使用这组原生颜色，确保浅色与深色模式下仍有合适的层次与对比。

自定义界面的标题、滑杆、边框和滚动条使用角色默认颜色，并根据当前明暗主题生成较深、较浅和透明版本。角色原色用于主要强调位置，Radix 原生色系负责需要多层颜色的控件。

## 状态关系

- 初次打开时，强调色来自默认角色。
- 选择角色后，角色、默认文字颜色和界面强调色同时更新。
- 手动修改文字颜色时，只改变贴纸文字，不改变界面强调色。
- 重置文字颜色时，恢复角色默认文字颜色，界面强调色保持不变。
- 系统明暗主题变化时，角色强调色不变，仅切换适合当前背景的明暗版本。

## 边界

- 不改变角色资料与贴纸颜色资料。
- 不改变 Canvas 绘制、贴纸预览或导出结果。
- 不增加新的依赖。
- 不提供独立的主题颜色选择器。
- 不要求界面颜色与角色原色的每个色值完全相同；优先保证 Radix 控件的一致性与可读性。

## 验证

- 初始界面使用默认角色对应的强调色。
- 选择不同色系的角色时，主要控件和自定义强调位置同步变化。
- 手动修改文字颜色时，界面强调色不变。
- 浅色与深色模式下均保持文字与控件清晰可辨。
- `pnpm lint` 与 `pnpm build` 通过。
