# 跟随系统的深色模式设计

## 目标

操作界面自动跟随系统的浅色或深色主题，并在系统主题运行时变更后立即切换。贴纸内容、预览画布、用户选择的文字与描边颜色，以及导出结果不受影响。

## 方案

应用读取 `prefers-color-scheme: dark`，将当前结果传给 Radix Themes 的 `Theme`。系统主题发生变化时更新该值，让 Radix 的按钮、输入框、选择器、开关和弹出内容使用原生对应外观。

自定义界面继续使用现有 CSS 变量。浅色值保持不变，在深色系统主题下覆盖页面背景、面板、分区、表单行、边框、文字、品牌色、滑杆与阴影。清除会阻止主题生效的固定浅色背景，并声明浏览器原生控件可使用浅色与深色配色。

不增加主题管理套件，不提供手动切换，也不保存主题偏好。

## 边界

- 只改变操作界面的颜色。
- 不改变 Canvas 绘制流程、贴纸图片或导出内容。
- 不改变文字颜色、描边颜色及其默认值。
- 不改变页面结构、尺寸、间距或操作流程。
- 不增加新的依赖。

## 状态与切换

首次打开页面时，以系统当前主题作为 Radix Themes 的外观。应用监听系统主题变化并即时更新；卸载时移除监听，避免残留事件处理。

若浏览器不支持主题查询，则使用浅色主题，现有功能不受影响。

## 验证

- 浅色系统下，界面保持现有浅色视觉与可读性。
- 深色系统下，页面、面板、文字、边框及 Radix 控件均使用协调的深色外观。
- 页面打开期间切换系统主题，界面无需刷新即可同步变化。
- 贴纸预览和导出结果在两种主题下保持一致。
- `pnpm lint` 与 `pnpm build` 通过。
